# Cloudflare Pages 站点接入 ARG 验证服务

此包用于**目标网站**，不是验证服务本身。它使用 Pages 高级模式的 `_worker.js`：每个请求先经过验证，受保护目录下的 HTML 和文件只有持有有效会话才能返回。无需将玩家账号或密码写入网页。

## 分工与准备

- 验证服务管理员在后台登记目标站点、设置玩家账号，并提供该站点的 ID、origin、保护目录及签名密钥。管理后台地址：`https://arg-auth-683dc0f14848.yangyi42905341.workers.dev`。
- Pages 网站的所有者负责配置自己的 Pages 项目。`SITE_KEY` 是敏感密钥，只应通过安全渠道交给需要配置它的站点所有者，并作为 Pages Secret 输入。不要将它写入聊天提示词、源码、Git 仓库、上传包或网页。
- 目标站点必须有固定的 HTTPS origin，例如 `https://my-website.pages.dev`；自定义域名同样可用。origin 不带路径、末尾斜杠或 `*`。默认生产域名、预览域名和自定义域名是不同 origin，需要分别考虑；本适配器只接受配置的一个 origin，其他 origin 返回 403。

## 接入步骤

1. 管理员在验证服务后台“登记站点”，填写目标 Pages origin、站点 ID、保护目录（例如 `/archive/`）和成功登录后跳转的路径（例如 `/archive/index.html`）；添加玩家账号与密码。必须让后台配置和下述 Pages 配置完全一致。
2. 将本包的 `_worker.js` 放在目标站点的**构建输出目录根部**，与输出的 `index.html` 同级；把所有需保护的页面和敏感资源放进保护目录。将登录页放在保护目录之外。可使用后台生成的登录表单，也可直接链接到 `https://arg-auth-683dc0f14848.yangyi42905341.workers.dev/login.html?site=站点ID`。
3. 在 Pages 项目的 **Settings → Variables and Secrets** 中为生产环境设置：

   | 名称 | 值 | 类型 |
   |---|---|---|
   | `AUTH_ORIGIN` | `https://arg-auth-683dc0f14848.yangyi42905341.workers.dev` | 普通变量 |
   | `SITE_ORIGIN` | 后台登记的目标站点 HTTPS origin | 普通变量 |
   | `SITE_ID` | 后台登记的站点 ID | 普通变量 |
   | `PROTECTED_PREFIX` | 后台登记的保护目录，例如 `/archive/` | 普通变量 |
   | `SITE_KEY` | 后台为该站点生成的签名密钥 | **Secret / Encrypt** |

   `SITE_KEY` 不属于浏览器登录代码，只能保存在 Pages 的 Secret 中。
4. 部署或重新部署 Pages。Git 集成需确保构建过程把 `_worker.js` 输出到构建目录；使用 Wrangler 或 Pages 控制台直接上传时，将整个构建输出目录上传，`_worker.js` 必须在根目录。变量和 Secret 修改后重新部署以确保生效。
5. 使用无痕窗口验证：公开页面可访问；直接打开保护目录中的页面、图片和文档会转到登录；错误密码被拒绝；正确密码验证后可读取目录内资源。也应检查无凭据时旧版本、预览 URL、自定义域名、公开副本和其他路径无法访问敏感内容。

如果是新 Pages 项目，需要先获得项目的生产 URL 才能在后台登记。可以先部署一个只含占位页面的空站点，取得 URL 后再登记并上传完整站点；在保护配置验证完成之前不要公开敏感文件。

## 重要兼容性

- `_worker.js` 是高级模式：它会接管全部请求，Pages 将忽略该项目的 `functions/`。如果原项目已有 `_worker.js`、Pages Functions 或服务端逻辑，必须由开发者**合并鉴权逻辑**并测试，不要直接覆盖原文件。
- 不要通过 `_redirects` 的重写或其他公开 URL 给保护目录中的文件建立别名，也不要保留未受保护的副本。仅靠隐藏链接、关闭搜索或前端跳转无法保护内容。
- `_worker.js` 必须确实进入每一次生产部署的构建输出。缺少变量时本适配器会拒绝请求，但缺少 `_worker.js` 的部署可能直接公开静态文件。旧部署和其他托管地址同样可能绕过保护。
- 当前适配器只保护一个目录前缀，站点一个目标 origin；增加目录或 origin 前应更新设计并验证所有访问路径。
- 新版适配器通过验证服务一次性兑换登录票据，并在每次访问受保护内容时检查会话；验证服务不可用时会返回 503。会话有效期为 8 小时；更改玩家密码不会立即使已发出的会话失效。
- 在需要退出的位置放置同源 POST 表单 `<form action="/_arg/logout" method="post"><button type="submit">退出</button></form>`。退出会撤销当前会话并清除浏览器 Cookie，其他独立登录会话不会受到影响。
