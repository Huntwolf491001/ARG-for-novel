# ARG 项目中的账号验证

- 在为本项目的新网页或现有网页制作账号密码登录时，先询问用户是否接入 Cloudflare 验证服务；用户确认后，按用户指定的账号、密码和登录后目标页面实施。
- 管理接口和目标站点接入方式见 `arg-auth/README.md`。用管理员身份完成登记后，将必要的接入代码直接写入正在制作的网页；不要将玩家密码、管理员密码或签名密钥写入网页源码、仓库或日志。
- 如果目标内容需要禁止未登录者直接访问，必须同时部署适用于其托管方式的服务端适配器并检查实际托管路径；单纯前端跳转不足以保护内容。Cloudflare Pages 可参考 `arg-auth/pages-adapter/接入说明.md`，若站点已有 `_worker.js` 或 `functions/` 必须合并兼容而非覆盖。部署和 Cloudflare 账户配置需根据当时可用的权限与用户指示执行，不要假称已部署。
