使用论坛时间（UTC+8），通过日期时间选单选择。未修改时间的历史记录保留原始精度。

稿件检查

导入时会按最新资料再核对一次。此处通过检查不代表已经发布。

作者变更

同一个角色的新身份应新建账号；修改已有账号会更新该账号全部页面上的昵称与资料。

交稿方式

  1. 编辑主题、回复和作者
  2. 检查冲突，导出 JSON 稿件
  3. 进入主站，使用管理账号登录
  4. 选择稿件，预检并确认导入

纯前端编辑与导入。资料保存在当前浏览器，作者可通过 JSON 或 ZIP 文件交换稿件。
