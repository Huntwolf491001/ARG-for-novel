狰州论坛 · Windows 便携预览

1. 将网站便携包复制到另一台 Windows 电脑，完整解压到普通文件夹。
2. 双击“启动网站预览.cmd”，浏览器会自动打开网站。
3. 保留启动窗口即可持续使用。关闭窗口或按 Ctrl+C 停止预览。

无需安装 Node.js、Python、数据库或 npm 依赖，也不需要管理员权限。
启动器使用 Windows 自带的 Windows PowerShell 与 .NET，只提供本机静态文件。
登录、编辑、文件导入和整库核验仍全部在浏览器中进行。

默认首页：http://127.0.0.1:4178/
管理入口：http://127.0.0.1:4178/login.html

迁移已有贴文与作者资料：
先在原电脑管理窗口“导出整库 ZIP”，到新电脑登录管理窗口后“导入整库 ZIP”。
不要把整库 ZIP 当作网站程序包；新电脑需要先解压完整的网站便携包。

浏览器资料按站点地址保存。建议一直使用默认地址、端口及同一浏览器配置。
如果端口 4178 被占用，先关闭其他预览程序。重复双击同一目录的启动器会复用
已经运行的本站预览，不会重复启动。

必须换端口时，可在命令行运行：
启动网站预览.cmd 4188
更换端口会使用另一份浏览器资料库，原数据需要通过整库 ZIP 迁移。

仅支持本机预览，不对局域网或公网开放。请勿直接在压缩包内运行启动器。
若电脑的组织策略禁止运行 PowerShell，请由设备管理员使用允许的静态托管方式。
