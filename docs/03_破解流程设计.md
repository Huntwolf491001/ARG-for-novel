## 零、三条设计原则

**一、线索必须"读"得出来，不能"猜"。**
每一个需要推理的地方，都要有至少两处文本作为依据。玩家卡住时，缺的是联想，不是运气。

**二、每一步都要有验证。**
玩家做完一个动作，必须立刻知道对不对——页面变了、解锁了、出现新东西。不能让人在黑暗里摸索。

**三、卡住时有第二条路。**
任何一关，都准备一条备用路径。它不能比主路容易，但必须存在。

---

## 一、主链六步

```
① 小说正文 → 网址
② 市局官网表层 → 三处异常 → 一个人名
③ 民间论坛 → 用户 00417 → 最后发帖日
④ 内网登录 → 00417 / 0817 → 后台
⑤ 卷宗 0714-甲 → 11 份档案
⑥ 核查结论 → 第 12 次借阅
```

## 二、逐步设计

### ① 入站

| 项 | 内容 |
|---|---|
| 玩家动作 | 读到正文某处出现的网址，试着输入 |
| 线索来源 | 小说正文（作者放置，建议放在一份旧文件的页眉或某个自然场景） |
| 验证 | 页面打开，是一个看起来完全正常的区/市公安局门户网站 |
| 关键 | **不能有任何"这是游戏"的痕迹**。玩家第一反应应该是"这网站真的存在啊" |

### ② 表层异常

玩家在官网随意浏览，会陆续撞上三处不对劲：

| 位置 | 内容 | 玩家会想 |
|---|---|---|
| 警务动态列表最底部 | 2022-08-18《黄石分局快速处置一起群体性事件》：「未发生人员伤亡」 | 十年前的一条新闻，为什么还挂在列表里 |
| 政务公开 → 人事任免 | 2022-09-20《关于狩岳同志免职的通知》 | 这个人是被免职的，但没写原因 |
| 市局概况 → 机构设置 → 刑事侦查支队 | 「支队长 严锋；副支队长一职自 2022 年 9 月起空缺」 | 免职和空缺是同一个月 |

**三处指向同一个人：狩岳。**

设计要点：这三处**都不在显眼位置**。旧闻要滚到列表底，免职通知在任免列表最后一页，机构设置里那一行藏在长句末尾。读者是"逛"出来的，不是被指路指过去的。

**验证**：没有任何提示。玩家自己开始搜索"狩岳"。

### ③ 跨站：从官方到民间

| 项 | 内容 |
|---|---|
| 入口一 | 页脚「友情链接」下拉框 →「狰州民间消息论坛」 |
| 入口二 | 新闻详情页正文末尾「来源：狰州日报」→ 可点进论坛的转帖 |
| 玩家动作 | 进论坛，搜索「狩岳」，或搜索「817」 |

论坛里的关键发现：

- 用户 **00417**，注册于 2015 年 3 月，发帖 37 条，**最后访问 2022-08-20 21:37**
- 签名档：「退了」
- 显示名就是「00417」，头像空白
- **最后一条发帖**：2022-08-16 22:41，《明天开会，回来再说》

玩家要把两件事对上：**官网上那个被免职的人，和论坛里这个 8 月 16 日说要开会、第二天起再没上过线的人，是同一个人。**

**验证**：用户页有明确的「最后访问时间」，帖子里有明确的发帖时间，两者都能点开对照。

### ④ 内网登录：两个数字怎么来的

| 数字 | 来源 | 推理 |
|---|---|---|
| **00417** | 论坛用户名 | 一个老警察用警号当网名，是常见习惯 |
| **0817** | 最后发帖日 + 官网旧闻日 | 他 8 月 16 日说「明天开会」，官网说 8 月 17 日出的事 |

**密码不是猜出来的，是读出来的。** 「明天开会」这句话加上「8·17 事件」，才拼出 0817。

登录页设计：

```
警号  [__________]
密码  [__________]

        [ 登 录 ]

忘记密码？请联系档案室内线 8041。
```

**关键容错**：密码接受三种写法——`0817`、`817`、`20220817`。任何一种都通过。

**失败提示**：输错一律提示「该账号已停用，请联系管理员」。

这句话有两个作用：
1. 让玩家知道**账号是对的**，不会在账号上反复浪费
2. 制造不安——为什么一个外人会拿到一个停用账号的警号

### ⑤ 卷宗

登录后是后台首屏，玩家看到：

```
当前账号    00417
姓　　名    狩 岳
账号状态    停用
所属部门    刑事侦查支队（原）
上次登录    2022-08-20  21:37:04
```

这个"上次登录"时间，和论坛里那个"最后访问 2022-08-20 21:37"**完全一致**。

玩家此时会明白：他登录过系统，也上过论坛，然后在同一天晚上消失了。

**他上来做什么？** 点开「我的待办」：

```
事项类型    申诉材料提交
发起时间    2022-08-18
截止时间    2022-08-21
当前状态    已逾期
备　　注    未提交
```

他看见了这条待办，没有提交，三天后逾期。

然后进入共享案卷 0714-甲，11 份档案。

### ⑥ 结论

三个下拉框：事件性质 / 举报人身份 / 处理建议。

填对（举报人 = 严锋）后，页面刷新出甲-11 的新一行：「借阅人：严锋，第 12 次，今日」。

## 四、卡点预案（备用路径）

| 卡在哪 | 备用路径 |
|---|---|
| 找不到论坛 | 「警民互动」页有「网上警民恳谈」入口，指向论坛的民生版块 |
| 论坛搜不到狩岳 | 直接搜「817」，会有大量帖子；再顺藤摸瓜找到 00417 的发言 |
| 不知道 00417 是账号 | 登录页提示「账号为警号」，而论坛用户名就是 00417 |
| 密码试不出来 | 论坛里另有一条帖子，标题是《817 那天到底发生了什么》，标题本身就是数字 |
| 卷宗看不懂 | 甲-11 阅卷登记表把「有人反复翻这份卷」摆在明面上，玩家可以反推"值得翻的东西在哪" |
| 结论填不出 | 甲-04 写着「有人找到我和另外一位同志」——写信人是被找的两人之一；永明改了记录（甲-09 记过），即「另外一位同志」；甲-08 调动申请的字迹与举报信不同，排除永明；剩下只有严锋 |

## 五、难度曲线

| 阶段 | 难度 | 性质 |
|---|---|---|
| ① 入站 | 极低 | 只需好奇 |
| ② 表层 | 低 | 浏览 + 注意 |
| ③ 跨站 | 中 | 搜索 + 联想 |
| ④ 登录 | 中高 | 两处文本合成一个数字 |
| ⑤ 卷宗 | 中 | 阅读 + 交叉 |
| ⑥ 结论 | 高 | 需要一次真正的判断 |

**第 ④ 步是分水岭。** 走到这里的玩家，会分成两类：试出来的，和想出来的。前者收获"我破解了"，后者收获"我认识这个人了"。

设计目标是后者。

## 六、现在还缺的（按紧急度）

| # | 缺口 | 影响 |
|---|---|---|
| 1 | 论坛不存在 | 主链 ③ 断开，整条路走不通 |
| 2 | 官网没有指向论坛的链接 | 玩家找不到入口 |
| 3 | 登录页未做多写法容错 | 玩家可能试到放弃 |
| 4 | 密码线索（「明天开会」那条帖）无处安放 | 密码变成猜谜 |
| 5 | 卷宗里缺"8·17 当天下午"的一手记录 | 玩家无法独立确认事件经过 |

**第 1 项是硬阻塞。** 论坛不做出来，后面所有设计都是纸上的。
