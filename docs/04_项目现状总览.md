## 一、这是什么

一套**虚构世界的 ARG（Alternate Reality Game）解谜站点群**，作为小说《食肉本能》的延伸内容。

读者在小说正文的某些情节里会看到一串网址，打开后发现是一个真实可访问的网站——看起来就是普通的政府或企业官网。但网站深处藏着与正文互为表里的另一层故事：正文里没讲明的动机、没写完的结局、被删掉的记录，都在这些站点里。

**设计原则：**

1. 每个站点单独看都是"正常"的，不解决任何问题
2. 只有把几个站点的信息交叉比对，才会发现矛盾
3. 所有线索必须能从站点内读出来，不靠猜
4. 站点内不得出现任何"这是虚构作品""本故事纯属虚构"的提示

### 3.6 视觉与技术特征

- **风格**：仿省厅级政府网站。政府蓝 `#1b4b8f`、字号偏小、边框多、渐变标题栏、"更多>>"
- **年代感**：黄色跑马灯（警方提示）、页脚访问计数器、2015 年建站声明、Powered by Discuz! 字样
- **浮窗**：右下角反诈提醒（4 条轮播）、左下角便民提示，均可关闭
- **辅助功能**：无障碍浏览（字体/高对比/适老/繁体四项）、适老模式、繁體切换
- **移动端**：已适配手机竖屏（820px / 480px 两档断点），导航横向滑动
- **印章**：卷宗内的公章为 SVG 绘制（双圈 + 弧形单位名 + 五角星 + 日期），采用「骑年盖月」压印方式

## 四、核心玩法：破解流程

```
① 读小说正文 → 看到网址 → 打开市局官网
         ↓
② 逛官网 → 发现三处不对劲 + 一份被撤回的文件 → 记住一个人名：狩岳
         ↓
③ 点页脚「内部办公」→ 登录框只认警号 00417
         ↓
④ 密码不知道 → 点「忘记密码？申请人工核验」
         ↓
⑤ 核验：手机号 138 7419 362 → 是否仍在使用
         ├─ 仍在使用 → 验证码已发送 → 死路（收不到）
         └─ 已停用 → 验证问题「您儿子的姓名」→ 输入「狩东」
         ↓
⑥ 申诉通道 → 二级密码 → 进入后台
         ↓
⑦ 我的待办 → 共享案卷 → 0714-甲 → 11 份档案
         ↓
⑧ 提交《核查结论》→ 触发第 12 次借阅记录
```

**关键设计：密码不是猜的，是读出来的。**

- 警号 `00417` 来自论坛里一个叫「00417」的沉默用户
- 手机号 `138 7419 362` 是线索而非验证手段——玩家拿它去论坛搜，才能找到狩岳的痕迹
- 验证问题「您儿子的姓名」→ 狩东：玩家要亲手打出这两个字，冒充一个父亲
- 二级密码目前为占位值，**尚无来源**（见第九章）

## 六、故事内核（剧透）

**2022 年 8 月 17 日**，方舟生物在黄龙会展中心举办新品发布会，场外聚集二百余人。刑侦支队副支队长**狩岳**现场指挥，下令使用警棍开道，造成 11 人受伤（3 人重伤）。

事后的处置链：

```
8-18  市局发通报；同日发新闻称「未发生人员伤亡」
9-06  督察支队移送线索（只提"处置失当"）
9-19  狩岳撤职；永明记过
9-21  《"8·17"通报》被撤回
```

**核心矛盾——两种忠诚：**

- **狩岳**：对现场二百人负责。他下令用警棍，是为了避免踩踏。他不辩解，也不申诉
- **严锋**：对制度负责。他写下实名举报信（甲-04），导致师傅被撤职。十年后他升任支队长，签了自己儿子的政审，还在反复借阅这卷档案（11 次）

**没有反派。** 举报的人是对的，被举报的人也是对的。这是整个项目的题眼。

## 七、世界观坐标

- **主线时间**：2032 年 7–11 月（正文现在时）
- **事件时间**：2022 年 8 月 17 日（十年前）
- **主角**：狩东，灰狼，2032 年从刑警学院毕业入警，分配至黄石分局
- **他是狩岳的儿子**——这件事他本人不知道（三岁丧母，父亲从不提）
- **严锋**：狩岳的徒弟，2022 年写举报信，2032 年已是刑侦支队支队长

其他势力（方舟、北朔、猄都、虹狮湾自由港）作为背景，暂未接入本线。

## 八、如何运行

纯静态站点，无后端、无数据库、无构建步骤。

```bash
cd site
python -m http.server 8801 --bind 127.0.0.1
# 访问 http://127.0.0.1:8801/
```

或任意静态服务器（Nginx / Cloudflare Pages / GitHub Pages）。

**注意**：所有路径为绝对路径（`/assets/...`），必须以站点根目录为服务根。
