# 狰州民间消息论坛 · 需求说明

> 版本 v1.0 · 2026-10-25
> 用途：对外同步给开发/设计协作方
> 关联项目：《食肉本能》ARG 系列站点

---

## 一、项目背景

这是一套虚构世界观（兽人社会刑侦题材）的 ARG 解谜站点群。读者在小说正文里拿到网址，访问这些网站，从中拼出正文没有讲明的另一层故事。

目前已完成三个站点：

| 站点 | 性质 | 状态 |
|---|---|---|
| 狰州市公安局门户网站 | 政府官网 | 已完成 |
| 方舟科技（Ark Technology） | 企业官网 | 已完成 |
| 北朔工业集团 | 企业官网 | 已完成 |

**本次要做的第四个站点：狰州民间消息论坛。**

---

## 二、这个站是什么

一个地方城市的综合论坛，类似 2010 年前后的地方贴吧 / Discuz! 论坛。

- **时间设定**：2032 年（站点内容最新到 2032 年 10 月）
- **用户构成**：本地市民、外来务工者、个体户、学生、退休老人
- **内容性质**：闲聊、民生投诉、二手交易、求职、爆料、吵架

**它承担一个特殊的叙事功能：它是"非官方说法"的集散地。**

举个具体例子，同一件事的三个版本：

- 市公安局官网写：「现场秩序及时恢复，未发生人员伤亡。」
- 论坛里有人发帖：「我表姐在会展中心上班，说那天抬出来好几个，担架都不够用。」
- 论坛另一人回复：「你表姐哪个部门的？我就在现场，根本没那回事，别造谣。」

**三个版本并列存在，谁都没被证伪。** 这就是这个站存在的意义。

## 三、页面清单

### 3.1 首页

- 顶部：站点名 + 用户信息区（未登录显示"登录 / 注册"）
- 版块列表（表格形式，每行一个版块：版块名、主题数、帖数、最后发表）
- 右侧栏：今日发帖榜、论坛统计（会员数、帖子数、在线人数）
- 底部：友情链接、备案信息、"Powered by Discuz!"

### 3.2 版块页

每个版块一页，帖子列表：

| 列 | 内容 |
|---|---|
| 状态 | 置顶 / 精华 / 已锁 / 无 |
| 标题 | 可点击进详情 |
| 作者 | 用户名（可点进用户页） |
| 回复/查看 | 数字 |
| 最后回复 | 时间 + 用户名 |

底部：页码（1 2 3 ... 下一页），每页 20 条。

### 3.3 帖子详情页

这是最重要的页面，需要还原老论坛的细节：

- 楼层编号（1 楼、2 楼、沙发、板凳）
- 左侧用户信息栏：头像（色块即可）、用户名、等级、帖子数、注册时间
- 右侧正文：文字、引用块、表情符号（用文字代替）
- 楼中楼回复（引用某楼）
- 编辑痕迹：「本帖最后由 XXX 于 2032-9-20 14:32 编辑」
- 被删状态：「该帖已被删除或正在审核」
- 锁帖状态：「本帖已被锁定，不再接受回复」

### 3.4 用户页

- 用户名、等级、积分、注册时间、最后登录
- 发帖记录列表（可点进帖子）
- 签名档（老论坛必有）

### 3.5 其他

- 搜索结果页（假搜索，可以只显示"功能维护中"）
- 登录 / 注册页（表单不做逻辑，提交后提示"账号或密码错误"）
- 站规 / 关于本站

**预估页面总数：60–70 个静态页。**

## 四、内容要求（重点）

### 4.1 帖子时间跨度

**必须覆盖 2015 年至 2032 年。**

不是所有帖子都新。至少要有一批 2015–2020 年的"坟帖"，它们显示的是那个年代的论坛生态。

时间分布建议：

| 年份 | 帖子占比 | 说明 |
|---|---|---|
| 2015–2018 | 15% | 论坛刚起步，帖子少、回复少、错别字多 |
| 2019–2021 | 20% | 逐渐活跃 |
| 2022 | 25% | **有一起重大事件引发大量讨论**（详见 4.3） |
| 2023–2030 | 25% | 日常 |
| 2031–2032 | 15% | 最新 |

### 4.2 帖子的"脏"度

这个论坛不能干净。必须包含：

- **水帖**：「沙发」「顶」「路过」「拿分走人」
- **广告帖**：「XX 驾校包过，电话 138xxxx」
- **吵架**：地域攻击、人身攻击、管理员警告
- **错别字与网络用语**：那个年代的用语习惯
- **太监帖**：楼主发一半不更了，下面一堆人骂
- **坟帖被顶起**：「谁把三年前的帖子挖出来了」
- **删帖痕迹**：「该帖已被删除」，但标题还留在列表里

### 4.3 关键事件线（作者提供，开发只需预留位置）

2022 年 8 月，本地发生一起群体性事件（会展中心，某企业发布会）。论坛上会有一批相关帖子，包括：

- 事发当天的现场描述
- 几小时后开始出现的质疑
- 被删除的帖子（只剩标题）
- 几个月后的"复盘帖"
- 十年后（2032 年）有人翻出旧帖

**这部分的具体帖子内容由作者提供，开发只需保证：帖子详情页能显示被删状态、能显示编辑痕迹、能显示锁帖状态。**

### 4.4 其他线索位（作者提供）

除事件线外，还需要在以下位置埋内容，具体文字由作者提供：

- 1–2 个"看起来很水但信息量很大"的帖子
- 1 个长期更新的连载帖（楼主坚持更新了几年）
- 1 个已被删除但通过搜索引擎快照能看到的帖子

## 五、视觉要求

### 5.1 总基调

**要旧、要土、要像 2010 年的 Discuz! 论坛。**

不要做成现代论坛：不要圆角卡片、不要大留白、不要 Material Design、不要交互动效。

### 5.2 具体规范

| 项目 | 要求 |
|---|---|
| 主色 | 深蓝 `#1e4d8c` + 灰白底 `#f5f5f5` |
| 字号 | 正文 12px，列表 12–13px，标题 14px |
| 字体 | 宋体 / 微软雅黑混用（老论坛常见） |
| 布局 | 表格感强，行高紧凑，边框 1px 实线 |
| 按钮 | 方角、灰底、1px 边框、按下有凹陷感 |
| 头像 | 不需要真实图片，用纯色方块 + 首字即可 |
| 图标 | 用文字符号代替（★ 精华、▲ 置顶、🔒 锁），不要引入图标库 |
| 分页 | 老式方块页码，当前页蓝底白字 |

### 5.3 必须有的"不完美"

- 部分链接点了没反应
- 部分图片是占位（灰色方块写"图片加载失败"）
- 底部版权年份不更新（写 2015–2032）
- 页脚有 ICP 备案号 + "Powered by Discuz! X3.2"

## 六、技术约束

| 项 | 要求 |
|---|---|
| 技术栈 | 纯静态 HTML + CSS，少量原生 JS |
| 后端 | 无。不接数据库、不存数据 |
| 依赖 | 不引入任何外部 JS 库、字体、CDN |
| 托管 | 静态托管（Cloudflare Pages 之类） |
| 目录 | 可多页面，也可单页切换，按开发者习惯 |
| 移动端 | 不要求响应式（老论坛本来就不适配手机），可做一个"请使用电脑访问"提示 |

---

## 七、绝对不要做的事

1. **不要用真实平台名**（不要出现百度贴吧、天涯、猫扑）
2. **不要出现真实地名、真实机构**
3. **不要做成现代化 UI**
4. **不要收集任何用户信息**（登录注册都是假的，不提交到任何地方）
5. **不要在帖子内容里暗示"这是虚构作品"**（不能出现"本故事纯属虚构"之类的提示）
6. **不要在页面里放小说原文**（论坛帖子是独立创作的内容）

---

## 八、交付标准

- [ ] 页面总数 60–70 个
- [ ] 所有内部链接可点击，无 404
- [ ] 帖子时间跨度覆盖 2015–2032
- [ ] 至少 15 条被删帖子（显示"已删除"状态）
- [ ] 至少 8 条锁帖
- [ ] 首页、版块页、帖子页、用户页四类页面齐全
- [ ] 在 1400px 宽度下无横向溢出
- [ ] 页面源码里不含作者真实信息、不含任何联系方式

## 九、参考对象

建议开发前先看一眼这些老站的样子（仅作风格参考，不要抄内容）：

- 2010 年前后的地方贴吧
- Discuz! X2 / X3 默认模板
- 老式论坛的"版块列表"表格

关键词：**密集、灰扑扑、字小、边框多、信息拥挤。**

## 十、需要作者提供的内容（开发前确认）

| 项目 | 数量 | 说明 |
|---|---|---|
| 关键帖正文 | 约 10 条 | 事件线相关，含被删帖的"残留标题" |
| 用户名单 | 约 30 个 | 用户名、等级、注册时间、签名档 |
| 版块名称与简介 | 8–10 个 | 需要符合本土城市论坛习惯 |
| 连载帖 | 1 个 | 内容由作者写，需跨年更新 |

其余水帖、广告帖、吵架帖，开发可按模板批量生成，作者最后过一遍即可。
